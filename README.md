
# IELTS Institute Website

A responsive and modern landing page for an IELTS Institute built with **React.js**.  
It includes reusable components, smooth animations, and a clean UI to provide users with an engaging experience.

---

## 🚀 Features
- Fully **responsive design** (works on mobile, tablet, and desktop).
- **Reusable components** (Navbar, Hero, Features, Testimonials, Footer).
- Smooth **animations & hover effects** for better user engagement.
- Clean **modular CSS** with organized stylesheets.
- Easy to customize and extend.

---



## 🛠️ Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/ielts-institute.git
   cd ielts-institute

2. **Install dependencies**
   npm install

3. **Run the development server**
  npm start

4. **Build for production**
  npm run build
